# serval-qgis4

Fork de [Serval](https://github.com/lutraconsulting/serval) (Lutra Consulting, GPL v2) portado a QGIS 4 (Qt6/PyQt6). Añade la herramienta **perfil longitudinal** (cota inicio → cota fin) para editar fondos de cauce sobre MDT.

## Instalación

Descarga el ZIP del repositorio (o de Releases), y en QGIS: *Complementos → Administrar e instalar complementos → Instalar a partir de ZIP*.
